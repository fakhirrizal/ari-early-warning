System Overview & Architecture

ARI - Accounts Receivable Intelligence
An AI-powered early warning system for B2B receivables, utilizing Gemini 3.8 Flash to detect payment risks before due dates.
ComponentTechnologyPurpose
FrontendVanilla JS, DataTables, ApexChartsLightweight, serverless SPA interface.
DatabaseSQLite (sql.js) + LocalStorageClient-side persistence without backend costs.
AI EngineGoogle Gemini 3.8 FlashScrapes public data and generates risk evidence.
Backend ProxyCloudflare WorkersSecures API keys and handles CORS.
HostingFirebase HostingGlobal CDN for fast deployment.
Note: For security reasons, API keys and backend proxy URLs are not exposed in the UI.
